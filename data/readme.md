## GTZAN Dataset

The GTZAN dataset is a collection of 1000 audio files, each representing a different genre of music. The dataset is split into 10 genres, with 100 files per genre.

### Downloading the Dataset

The GTZAN dataset can be downloaded from the following link:

[GTZAN Dataset](https://www.kaggle.com/datasets/andradaolteanu/gtzan-dataset-music-genre-classification)
